# 背景画の作り方（GPT 画像生成ガイド）

「かくれさま」の背景は **ChatGPT（GPT の画像生成）で描き、シーンエディタで当たり判定を付ける** という流れで作ります。
ゲーム側は画像のサイズや形式を問わないので、生成された画像をそのまま使えます。

---

## 作業の流れ

1. 下の「共通スタイル」＋「各夜のプロンプト」を ChatGPT に貼って背景画を生成する
2. 気に入った1枚を保存し、`scenes/<ID>/bg.webp`（または `.png` / `.jpg`）として置く
   - 例：第二夜なら `scenes/ch2/bg.webp`
   - PNG のままだと 2〜3MB になるので、[Squoosh](https://squoosh.app/) などで WebP（品質 80 前後）に変換するとスマホでの読み込みが速くなります
3. ローカルサーバーを立てて `editor.html` を開く（README 参照）
4. 「サーバー上のシーンを開く」で `ch2` を選ぶ → 画像が読み込まれる
5. **実際に絵の中に描かれている小物** を四角・円・多角形で囲み、名前を付ける（10〜15個が目安）
6. 「テストプレイ」で遊んで確認
7. 「scene.json を保存」→ `scenes/ch2/scene.json` を上書き

> ⚠️ GPT はプロンプトで頼んだ小物を全部描くとは限りません。**プロンプトの小物リストにこだわらず、画像に実際に描かれた物から選んで** 名前を付けてください。逆に、頼んでいない面白い物が描かれていたら積極的に採用しましょう。

---

## 共通スタイル（毎回プロンプトの先頭に付ける）

```
アイテム探しゲーム（ヒドゥンオブジェクトゲーム）の背景画を1枚描いてください。

【画風】
・和風ホラー。昭和中期の日本の山村にある古い屋敷。
・写実寄りのデジタルペインティング。細部まで描き込まれた密度の高い絵。
・夜。青みがかった月明かりと、蝋燭や行灯の暖色の灯りが混ざる。
・不気味だが、小物の形がはっきり判別できる明るさを保つ（真っ暗にしない）。

【構図】
・横長 3:2。正面からやや見下ろす、舞台セットのような構図。
・画面の隅々まで、小さな生活道具や古道具がたくさん散らばっている。
・小物のいくつかは、他の物の陰や影に半分隠れている。
・小物は互いに重なりすぎず、それぞれ輪郭が分かるように配置する。

【禁止】
・人物は描かない（影や気配はよい）。
・文字・看板・ロゴ・ウォーターマークを入れない。
・血や残酷な表現は入れない。怖さは「気配」と「違和感」で表現する。
```

### 生成のコツ

- 1回で決めず、**3〜4枚出して一番「物が多く、見分けやすい」ものを選ぶ** のがおすすめです
- 物が少ないときは「もっと小物を増やして、画面全体に散らばらせて」と追加で頼む
- 暗すぎるときは「全体を一段明るく。小物の輪郭が見えるように」と頼む
- 同じ屋敷の統一感を出したいときは、前の夜の画像を添付して「この絵と同じ屋敷・同じ画風で、別の部屋を」と頼む
- **文字は入れない** のが安全です（GPT の日本語の文字は崩れやすいため）

## 各夜のプロンプト

共通スタイルの後ろに続けて貼ってください。「探す物の候補」は絵に入れてほしい物の例です。

### 第一夜　仏間（`scenes/ch1/`）

> 現在は仮の SVG 背景（`bg.svg`）が入っています。GPT の絵に差し替える場合は、新しい画像を置いて `scene.json` の `image` を変え、エディタで当たり判定を描き直してください。

```
【場面】古い屋敷の仏間。左に月明かりの透ける障子、中央に掛け軸のある床の間、右に扉の開いた黒漆の仏壇。
畳の上と床の間、仏壇の中に古道具が散らばっている。障子にうっすらと人影が映っている。
【描いてほしい小物】日本人形、鈴、お札、櫛、蝋燭、手鏡、古い鍵、狐面、番傘、数珠、湯呑み、古い写真、線香立て、おりん、扇子、巾着、草履、提灯
```

### 第二夜　土間と台所（`scenes/ch2/`）

```
【場面】古い屋敷の土間と台所。かまど、水瓶、木の流し台、吊り棚。上がり框の上に食べかけの膳が一人分残されている。
かまどの灰に小さな裸足の足跡が続いている。勝手口の戸が少しだけ開いて、外の闇がのぞいている。
【描いてほしい小物】茶碗、箸、鉄瓶、柄杓、すり鉢、しゃもじ、包丁、まな板、ざる、徳利、杓文字、マッチ箱、たわし、手ぬぐい、風鈴、羽釜、梅干しの瓶、草鞋
```

### 第三夜　蔵（`scenes/ch3/`）

```
【場面】屋敷の裏にある古い土蔵の中。天井近くの小窓から月光が一筋差し込み、埃が舞っている。
長持、箪笥、葛籠、木箱が積み上がり、古い着物が衣桁に掛かっている。長持の蓋がわずかに開いている。
【描いてほしい小物】古い帳面、算盤、印鑑、火鉢、行灯、雛人形、こけし、羽子板、独楽、太鼓、能面、巻物、硯、筆、錠前、和傘、糸巻き、からくり人形
```

### 第四夜　井戸のある裏庭（`scenes/ch4/`・懐中電灯モード）

> この夜は暗闇の中を懐中電灯で照らして探すモードです。**絵自体は普通の明るさで描いてOK**（暗くするのはゲーム側でやります）。

```
【場面】屋敷の裏庭。中央に木の蓋が半分ずれた古井戸。石灯籠、苔むした庭石、枯れた柿の木、壊れた物干し竿。
奥に竹林と、屋敷の縁側。地面に落ち葉と古道具が散らばっている。霧が低く立ち込めている。
【描いてほしい小物】桶、釣瓶、鎌、鍬、竹ぼうき、下駄、手毬、風車、お地蔵様の赤いよだれかけ、割れた鏡、ブリキの玩具、提灯、虫かご、麦わら帽子、縄
```

### 第五夜　村はずれの社（`scenes/ch5/`）

```
【場面】森の奥にある小さく荒れた神社。朽ちかけた赤い鳥居、苔むした狛犬、小さな本殿。
本殿の格子戸の奥に丸い鏡が祀られている。境内に奉納された古い人形や絵馬が積み重なっている。
【描いてほしい小物】絵馬、鈴緒、賽銭箱、御神酒の徳利、榊、紙垂、狐の像、おみくじ、注連縄、木札、灯籠、古い人形、手水の柄杓、破れた提灯、数珠
```

### 終夜　鏡の間（`scenes/ch6/`・懐中電灯モード）

```
【場面】屋敷の奥に隠された座敷。壁一面に大小さまざまな古い鏡が掛けられ、いくつかは布で覆われている。
中央に古い鏡台。床には子供の玩具と、これまでの部屋で見かけた品々（人形、鈴、櫛、狐面など）が散らばっている。
【描いてほしい小物】鏡台、手鏡、櫛、簪、紅入れ、白粉の箱、手毬、お手玉、おはじき、折り鶴、日本人形、狐面、鈴、古い写真、子供の草履、懐中時計
```

## 驚かし画像（任意）

見誤りが続いたときに一瞬出る「かくれさま」の顔は、今は SVG の簡易な絵です。
`assets/scare.webp` を置くと自動でそちらに差し替わります（縦横どちらでも可。画面いっぱいに表示されます）。

```
和風ホラー映画のワンシーン。真っ暗な背景に、長い黒髪で顔の大半が隠れた白い着物の女性が、
髪の隙間からこちらを覗き込んでいるアップ。肌は青白く、目だけがかすかに光っている。
写実的、フィルムグレイン、低彩度。血や傷などの残酷な表現はなし。文字なし。
```

> GPT は過度に残酷・グロテスクな画像は生成を断ることがあります。上のように「気配」「覗き込み」で怖さを出すと通りやすいです。

## ファイル早見表

| 置き場所 | 中身 |
|---|---|
| `scenes/index.json` | 夜の並び順（ID の配列） |
| `scenes/<ID>/scene.json` | タイトル・物語文・アイテムの当たり判定（エディタで作る） |
| `scenes/<ID>/bg.webp` | 背景画（GPT で作る） |
| `assets/scare.webp` | 驚かし画像（任意） |
