# 依頼の作り方（写真・依頼文・当たり判定）

このゲームでは、ステージを **「依頼」単位** で作ります。依頼 1 件に必要なものは次の 3 つです。

| 素材 | 内容 | 作るもの |
|---|---|---|
| 写真 | 異常が写り込んだ写真 1 枚（3072×2048） | GPT |
| 依頼文 | 依頼者・地域・本文、除霊の一文、鑑定結果、真相 | 人（文章） |
| 当たり判定 | 霊障の **核**（1 つ）と **痕跡**（4〜6 個）の位置と所見 | エディタ |

除霊後の写真は作りません。除霊の瞬間は、同じ写真の上の演出（核に札が貼られ、写真が光って静まる）で見せます。

---

## 1. 依頼を設計する（絵より先に）

異常は「GPT が描いたものから選ぶ」のではなく、**先に決めてから描かせます**。

- **核**：霊障の原因。「祓」で指して除霊する場所。1 つだけ
- **痕跡**：核とは別の小さな異常。4〜6 個。見つけると所見（短い一文）が出る
- **依頼文のヒントは 2 つ程度**：核や痕跡のありかを、自然な形でほのめかす。「テレビを見ろ」とは書かない
- **依頼者も知らない異常を混ぜる**：依頼文に出てこない痕跡がある方が怖い
- **鑑定結果で情報を足す**：除霊後に、依頼者が知らなかった事実が明かされる。痕跡を全部見つけた人だけが読める「真相」も書ける

例：依頼 No.001「祖母の家」（`requests/001/request.json` に入っています）

| | 内容 | 依頼文のヒント |
|---|---|---|
| 核 | 壊れたテレビの黒い画面に映る顔（祖母ではない） | 「夜になるとテレビの音がする」「テレビは壊れている」 |
| 痕跡 | 奥の部屋の障子の隙間からのぞく目 | 「夜は奥の部屋を開けるな」 |
| 痕跡 | 奥の部屋からテレビへ続く濡れた足跡 | なし（依頼者は知らない） |
| 痕跡 | 障子に映る人影 | なし |
| 痕跡 | 顔だけ黒く塗り潰された遺影 | なし |
| 痕跡 | 手鏡に映る知らない女の顔 | なし |

---

## 2. 写真を作る（GPT）

異常を狙った場所に一発で描かせるのは難しいので（経験則・信頼度 70%）、**2 段階** で作るのがおすすめです。

1. **普通の部屋の写真** を作る（下の「共通スタイル」＋「場面」）
2. **GPT の画像編集** で、異常を 1 つずつ足す（「この写真の、○○の位置に△△を、目立たないように足して」）

編集すると、直していない部分まで少し変わることがあります（経験則・信頼度 70%）。気になる場合は、編集のたびに前の写真と見比べてください。

### 共通スタイル（毎回プロンプトの先頭に付ける）

```
心霊写真として依頼者から送られてきた、実在しそうな一枚の写真を作ってください。

【写り】
・素人がスマートフォンかフィルムカメラで、部屋全体を記録のために撮ったような写真。
・作品っぽい構図や照明にしない。少し傾き、フラッシュの反射、わずかなブレや粒子がある。
・日本の地方の、生活感のある古い家。
・暗すぎず、置いてある物の輪郭がはっきり分かる明るさ。

【構図】
・横長 3:2。部屋の全体が入る引きの構図。
・画面の上下の端（各 8%）と左右の端（各 4%）には大事な物を置かない。
・小物がほどよく置いてあり、異常を足せる余地（暗がり、ガラス、鏡、隙間）がある。

【禁止】
・文字・看板・ロゴ・ウォーターマーク。
・血や残酷な表現。
```

### 依頼 No.001「祖母の家」の場面（1 段階目）

```
【場面】祖母が亡くなって空き家になった長野の古い家の仏間。片付けを始める前の状態。
左に奥の部屋へ続く障子（少しだけ開いている）、中央に床の間、右に扉の開いた仏壇。
畳の上に、古いブラウン管テレビが木の台に載っている（画面にひびが入っていて、明らかに壊れている）。
仏壇の下段に遺影。畳の上に手鏡、座布団、湯呑み、数珠などが置いてある。人物は写っていない。
```

### 異常を足す（2 段階目・1 つずつ）

```
この写真のテレビの黒い画面に、ぼんやりとした人の顔がうっすら映り込んでいるようにしてください。
よく見ないと気づかない程度の薄さで。ほかの部分は変えないでください。
```

同じ形で、「障子の隙間の奥に片目」「障子から台まで続く濡れた裸足の足跡」「障子に映る人影」「遺影の顔だけ黒く塗り潰す」「手鏡に知らない女の顔」を 1 つずつ足します。

---

## 3. 仕上げて置く

1. できた写真を **AI アップスケーラーで 2 倍（3072×2048）** にする（[Upscayl](https://upscayl.org/) など）
2. WebP（品質 85 前後）に変換する（[Squoosh](https://squoosh.app/) など）
3. `requests/<依頼番号>/photo.webp` として置く（例：`requests/002/photo.webp`）
4. `requests/index.json` の `"requests"` に依頼番号を足す

規格の詳細は [ASSETS.md の A-1](ASSETS.md#a-1-依頼の写真依頼-1-件につき-1-枚必須) にあります。

---

## 4. エディタで当たり判定を付ける

1. `npm run serve` で開発サーバーを起動し、`http://localhost:8000/editor.html` を開く
2. 「サーバー上の依頼を開く」で依頼番号を選ぶ（新しい依頼なら「画像を開く」で写真を読み込む）
3. 依頼番号・題名・依頼者・依頼文・除霊の一文・鑑定結果・真相を入力する
4. 写真の異常を四角・円・多角形で囲み、名前と所見を書く
5. 霊障の核にした 1 つに「核」のチェックを入れる
6. 「テストプレイ」で遊んで確認する
7. 「request.json を保存」して `requests/<依頼番号>/request.json` を上書きする

## 驚かし画像（任意）

見誤りが続いたときと、「祓」で外したときに一瞬出る顔は、今は SVG の簡易な絵です。
`assets/scare.webp`（2560×1440、顔は中央の幅 50% 以内）を置き、`requests/index.json` に `"scare": "assets/scare.webp"` を書き足すと、そちらに差し替わります。

```
和風ホラー映画のワンシーン。真っ暗な背景に、長い黒髪で顔の大半が隠れた白い着物の女性が、
髪の隙間からこちらを覗き込んでいるアップ。肌は青白く、目だけがかすかに光っている。
写実的、フィルムグレイン、低彩度。血や傷などの残酷な表現はなし。文字なし。
```

> GPT は過度に残酷・グロテスクな画像は生成を断ることがあります。「気配」「覗き込み」で怖さを出すと通りやすいです。

## ファイル早見表

| 置き場所 | 中身 |
|---|---|
| `requests/index.json` | 依頼の並び順・導入文・タイトルの副題 |
| `requests/<依頼番号>/request.json` | 依頼文・鑑定結果・核と痕跡の当たり判定（エディタで作る） |
| `requests/<依頼番号>/photo.webp` | 依頼の写真（GPT で作る、3072×2048） |
| `assets/scare.webp` | 驚かし画像（任意） |

ストア用の画像や音など、写真以外の素材の規格は [ASSETS.md](ASSETS.md) にまとめています。
