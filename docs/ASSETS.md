# 素材発注書（必要な素材と規格）

「かくれさま」を **iPhone / iPad（App Store）・Android（Google Play）・PC（Steam：Windows / macOS）** で販売するために必要な素材の一覧です。
すべて **横持ち（ランドスケープ）専用** です。

- 「信頼度」は規格値の確からしさです。**一次** ＝ 各ストアの公式ドキュメントで確認したもの、**二次** ＝ 公式の検索結果要約・解説サイト経由で確認したもの、**推奨** ＝ 公式の決まりではなく、このゲームの実装に合わせた本プロジェクトの指定です
- ストアの規格は変わることがあります。**提出の直前に、末尾の「出典」で最新値を必ず確認してください**
- 置き場所のパスはリポジトリ直下からの相対パスです。ファイル名を守れば、コードを変更せずにゲームへ反映されます

## A. ゲーム内の素材

### A-1. 依頼の写真（依頼 1 件につき 1 枚）★必須

ステージは「依頼」単位で作ります。依頼 1 件 ＝ **写真 1 枚 ＋ 依頼文 ＋ 当たり判定**（核 1 つと痕跡 4〜6 個）です。除霊後の写真は作りません。

| 項目 | 規格 | 信頼度 |
|---|---|---|
| 枚数 | 依頼 1 件につき 1 枚。依頼 No.001 は今は仮の SVG | 推奨 |
| 生成 | GPT で 1536×1024（3:2）で生成 → **AI アップスケーラーで 2 倍**にする（Upscayl〈無料〉、Real-ESRGAN、Topaz など） | 推奨 |
| **納品サイズ** | **3072 × 2048 px（3:2）**。全機種共通（PC 用の高画質版は作らない） | 推奨 |
| 形式 | WebP（品質 85 前後）、1 枚 2MB 以下が目安。原本の PNG は別途保管 | 推奨 |
| 色空間 | sRGB | 推奨 |
| 置き場所 | `requests/<依頼番号>/photo.webp`（例：`requests/002/photo.webp`） | — |
| 構図の安全域 | 核と痕跡は **上下 各 8%・左右 各 4% の外側に置かない**（細長い画面で切れる／指が届きにくい） | 推奨 |
| 異常 | **核 1 つ ＋ 痕跡 4〜6 個**。先に決めてから、画像編集で 1 つずつ足す | 推奨 |
| 写り | 素人が記録のために撮ったような写真（作品っぽくしない） | 推奨 |
| 禁止 | 文字・ロゴ・血や残酷な表現 | 推奨 |

**サイズの理由**：PC（1920×1080 以上）で 2.5 倍まで拡大しても粗くならないようにするためです。GPT の出力（1536×1024）のままだと、フル HD の画面で拡大すると目に見えてぼやけます。

依頼の設計の仕方、プロンプト、作業手順は [ART_GUIDE.md](ART_GUIDE.md) にあります。写真ができたら `editor.html` で当たり判定を付けます。

### A-5. BGM 任意（無い場合は合成の環境音が流れる）

| 項目 | 規格 | 信頼度 |
|---|---|---|
| 曲数 | タイトル 1 曲 ＋ 調査中の曲 2〜4 曲。依頼ごとに使い回してよい | 推奨 |
| 長さ | 60〜120 秒の **ループ曲** | 推奨 |
| 制作原本 | WAV 48kHz / 24bit ステレオ | 推奨 |
| **納品** | **AAC（.m4a）48kHz ステレオ 160〜192kbps** | 推奨 |
| ラウドネス | 積算 −16 LUFS 前後、ピーク −1 dBTP 以下（モバイルゲームの慣行値） | 推奨（業界慣行・二次情報） |
| ループ | ループ開始・終了の位置を **秒（小数）で指定**してもらう（AAC は頭に無音が入るため、ファイル全体をそのままループさせると継ぎ目で途切れる） | 推奨 |
| 置き場所 | タイトル：`assets/audio/bgm_title.m4a` ／ 各依頼：`requests/<依頼番号>/bgm.m4a` | — |
| 設定 | 各依頼の `request.json` に `"bgm": { "src": "bgm.m4a", "loopStart": 2.15, "loopEnd": 98.40 }`<br>タイトルは `requests/index.json` に `"audio": { "bgm": { "title": { "src": "assets/audio/bgm_title.m4a", "loopStart": 0, "loopEnd": 64.0 } } }` | — |
| 曲調 | 箏・尺八・鈴・低いドローン。旋律は控えめに（探しものの集中を妨げない） | 推奨 |

**AAC を選ぶ理由**：iOS / Android の WebView と PC 版（Electron）のすべてで確実に再生できる形式だからです（信頼度：推奨・80%。Ogg は iOS での対応状況に不安があるため避けています）。

## B. アプリのアイコン・起動画面

**原画を 1 セット作れば、各サイズは自動で書き出せます**（`npm run assets`。Capacitor Assets が iOS / Android 用のサイズを全部作ります）。今は仮の絵が入っています。

### B-1. アイコン原画 ★必須

| ファイル | サイズ | 内容 | 信頼度 |
|---|---|---|---|
| `resources/icon-only.png` | **1024 × 1024 px** | 完成形のアイコン（iOS・App Store 用）。**透過なし**、角丸なし（OS が丸める） | 一次（App Store は 1024×1024・アルファなし） |
| `resources/icon-foreground.png` | **1024 × 1024 px** | Android アダプティブアイコンの前景。**背景透過**。絵柄は **中央の直径 66%（約 676 px）以内**に収める | 一次（108dp のキャンバスに対して 66dp が安全域） |
| `resources/icon-background.png` | **1024 × 1024 px** | Android アダプティブアイコンの背景。透過なしの単色か模様 | 一次 |
| `resources/desktop/icon.png` | **1024 × 1024 px** | PC 版の実行ファイルのアイコン（Windows の .ico / macOS の .icns は自動で変換） | 推奨 |
| Google Play 用 | **512 × 512 px、32bit PNG、sRGB、1024KB 以下**、正方形のまま（角丸・影は付けない） | 一次 |
| Steam 用 | C-3 を参照 | — |

デザインの注意：
- 小さく表示されても判別できるよう、**モチーフは 1 つ**（例：髪に隠れた顔、狐面、鈴）
- 文字を入れない（小さいと読めないため）
- iOS 26 以降は「Liquid Glass」のレイヤー式アイコン（Icon Composer）や、ダーク／ティント版にも対応できます。必須ではありませんが、対応するなら前景・背景を分けた原画（上の foreground / background）が流用できます（信頼度：二次・70%）

### B-2. 起動画面（スプラッシュ）

| ファイル | サイズ | 内容 | 信頼度 |
|---|---|---|---|
| `resources/splash.png` | **2732 × 2732 px** | 中央にロゴ。**ロゴは中央の 1200 × 1200 px 以内**（端末によって四方が大きく切れるため） | 推奨（Capacitor Assets の入力サイズ） |
| `resources/splash-dark.png` | 2732 × 2732 px | ダークモード用（同じ絵で可） | 推奨 |

## D. スクリーンショットの撮り方（全ストア共通）

依頼の写真を入れた後、PC 版で **3840 × 2160 で撮り、各サイズに切り出す** と 1 回の撮影で全ストア分がそろいます。

| 撮るもの | 何枚 |
|---|---|
| 依頼文が重なった最初の画面（1 枚目に最適） | 1 |
| 調査中の画面（痕跡の所見が出ている瞬間） | 2 |
| 「祓」で核を指定している画面 | 1 |
| 除霊の瞬間（札が貼られる） | 1 |
| 鑑定結果の文章 | 1 |
| 依頼箱 | 1 |

- iPhone 用（2868×1320 など）は横長なので、上下を少し切るか、左右に余白をつけずに **画面を拡大した状態で撮る**
- iPad 用（4:3）は左右を切る
- 驚かしの顔を 1 枚目にしない（ストアの審査・年齢区分の印象が悪くなる）
